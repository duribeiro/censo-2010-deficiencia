# Política de segurança

## Reportar uma vulnerabilidade

Este projeto usa o recurso de relato privado de vulnerabilidades do GitHub (private vulnerability reporting).

Para reportar, acesse a aba "Security" do repositório e clique em "Report a vulnerability". Não abra uma issue pública para falhas de segurança.

O relato é privado entre você e os mantenedores até que a correção seja publicada.

## Escopo

Como o painel é um site estático que lê um conjunto de dados público do IBGE, o principal risco de segurança é em dependências (supply chain) e em configuração de build/deploy, não em dados sensíveis: o projeto não coleta, armazena nem processa dados pessoais.
