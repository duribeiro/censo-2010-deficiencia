# Changelog

Este projeto segue o formato do [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/).

## Não lançado / 0.0.2

### Planejado

- Dados via API pública do IBGE (SIDRA), habilitados pela variável de ambiente `VITE_DATA_SOURCE=sidra`.

## 0.0.1

### Adicionado

- Painel com conjunto de dados estático do Censo 2010 sobre pessoas com deficiência.
- Cards de indicadores, gráfico de área por estado e gráfico empilhado por tipo de deficiência.
- Tabela ordenável com filtros por região, estado e tipo de deficiência.
- Tema claro e escuro.
